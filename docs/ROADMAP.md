# MindForge Roadmap

## M1 — Playable & Auditable Skeleton
Godot project, Git/GitHub task workflow, player movement, room transitions, HUD, and deterministic run state.

## M2 — Puzzle Core
Three puzzle families, common content contract, deterministic solvers/validators, hint ladders, fingerprints, and local puzzle bank.

## M3 — Adaptive Intelligence
Skill vector + confidence, predicted-success model, target-success bands, anti-oscillation, recovery mode, calibration, and variety-aware scheduling.

## M4 — Progression & Persistence
Scoring, XP, feedback, run summary, atomic/versioned save/load, recovery, and feedback hooks.

## M5 — Procedural Dungeon
Seeded run generation, difficulty-aware rooms, family rotation, local procedural content, validation pipeline, and boss rooms.

## M6 — AI Content Layer
Optional secure AI proxy, solver-first structured generation, sanitization, quarantine, deduplication, cache, asynchronous pre-generation, and offline fallback.

## M7 — Analytics & Balance
Telemetry provenance, simulated players, convergence/oscillation/recovery metrics, empirical puzzle calibration, and adaptive-vs-static experiments.

## M8 — Release Hardening
Headless tests, accessibility, art/audio cleanup, performance, exports, GitHub Actions, licensing/security audit, and portfolio demo.

## Portfolio Release Target

A polished 15–25 minute graphical run that visibly adapts differently for strong, average, and struggling players while remaining reproducible and fully playable offline.

The GitHub repository should show a clean task-by-task development history rather than one giant final commit.
