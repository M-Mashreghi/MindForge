# Game Design Rules

Prioritize readable graphical 2D interaction and short feedback loops.

A room should normally contain one primary challenge and a clear success state.

Use progressive onboarding:
- first exposure teaches,
- second confirms,
- later rooms combine skills.

Difficulty adaptation should feel natural, not visibly manipulative.

Reward success with visible feedback such as score, XP, animation, room unlock, or loot.

Do not label the player as weak/strong.

Do not use shorter timers as the primary way to create difficulty.

Balance difficulty fit with puzzle variety. The numerically closest puzzle is not automatically the best next puzzle.

The core local/procedural game must be fun before AI content is enabled.
