# Documentation Rules

Keep these synchronized:
- `docs/PROJECT_PHASES_AND_TASKS.md`
- `docs/TASKS.md`
- `docs/GAME_DESIGN.md`
- `docs/ARCHITECTURE.md`
- `docs/ADAPTIVE_DIFFICULTY.md`
- `docs/PUZZLE_SPEC.md`
- `docs/GIT_WORKFLOW.md`
- `README.md`

Every completed task records:
- implementation summary,
- tests/validation run,
- relevant balance/design decision,
- Git commit hash after commit,
- push status when GitHub is configured.

All project documentation and code comments are written in English.
